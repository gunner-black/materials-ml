## Description of the project
This repository is a **Digital Laboratory Notebook** that builds a bridge between classical Materials Engineering and Materials Informatics (*Materials Informatics*).
The main objective is to translate the fundamental theory of materials science to the computational environment, using **algorithms and Machine Learning** to predict properties, automate physical calculations and analyze material data efficiently.
The theoretical basis and primary source of the data structured in this project are entirely based on the classic work:
> **Main Reference:** CALLISTER, William D. *Ciência e Engenharia de Materiais: Uma Introdução*. 8ª Edição. Rio de Janeiro: LTC, 2012.

## 🎯 Objectives
1. **Scan Theory:** Consolidate the concepts of the textbook in "Wiki-Book" format associated with this repository.
2. **Apply Machine Learning:** Use tabulated data (such as Callister appendices) to train predictive models of physical, mechanical, and thermal properties.
3. **Scientific Automation:** Develop Python scripts to automate crystallography, thermodynamics, diffusion, and phase engineering calculations.

4. ## How to Browse This Project
The project is divided into two integrated fronts: **Wiki (Theory)** and **Notebooks (Computational Practice)**.
